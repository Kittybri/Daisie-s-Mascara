`analysis/scripts/` contains the contributor's analysis and deck-generation scripts. `analysis/output/` contains archival aggregate analysis, including dataset profiles, exploratory comparisons, model experiments, and simulations. These research outputs do not establish the live extension's detection performance or a deployed network's effectiveness.

No raw source workbook is included here. Raw dataset row, URL, and title examples have been omitted from the public output logs. Aggregate tables retain their counts and rates; where necessary, rank numbers replace dataset identifiers. The scripts are preserved as contributed and can regenerate sample records when run locally, so review generated output before publishing it.

The main repository's product and architecture documentation defines the implemented extension and the proposed network. These supplemental drafts are retained for reference and do not replace that documentation or the five-slide deliverable.
